# Lección 3: Elementos HTML comunes (9 min)

**Objetivo:** usar encabezados, párrafos, listas, imágenes y enlaces.

1. (0:00) Encabezados `<h1>` a `<h6>`: el título es `<h1>`, los subtítulos son `<h2>`.
2. (1:30) Párrafos `<p>`.
3. (2:30) Listas con `<ul>` y `<li>`.
4. (4:00) Imágenes con `<img src="..." alt="...">`. Explicar por qué existe `alt`.
5. (5:30) Enlaces con `<a href="...">`.
6. (6:30) **Pausa de práctica:** agregar una lista de tus gustos, una imagen y un enlace.
7. (8:30) Comparar con `/completed-examples/lesson3-completed.html`.

# webdev-course-devsteam

Curso de 1 hora de **Fundamentos de Desarrollo Web (HTML y CSS)** para estudiantes de secundaria (12 a 17 años) sin experiencia previa.

No hay que instalar nada: todo se practica en editores en línea gratuitos (CodePen, JSFiddle, Replit) desde el navegador.

## Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| `/starter-files` | Código inicial que se pega en el editor en línea al comenzar cada práctica |
| `/completed-examples` | Código final de cada lección, para comparar |
| `/scripts` | Guion de narración y texto en pantalla de cada video |

## Cómo usar los archivos

1. Abre el enlace de práctica de la lección (ver el documento de plan de curso).
2. Si el editor aparece vacío, abre el archivo de `/starter-files` de esa lección, copia el contenido y pégalo en el editor.
3. Sigue el video y haz las pausas de práctica.
4. Compara tu resultado con la carpeta `/completed-examples`.

## Configuración

No se requiere configuración. Solo un navegador web: Chrome, Firefox, Safari o Edge.

# Lección 1: ¿Qué es un sitio web? (6 min)

**Objetivo:** entender qué es un sitio web y que se construye con contenido (HTML) y estilo (CSS).

| Minuto | Texto en pantalla | Narración |
|---|---|---|
| 0:00 | "¿Cómo se hace una página web?" | Pregunta de apertura: ¿alguna vez te preguntaste cómo se hace la página que visitas todos los días? |
| 0:45 | Navegador → pedir página → recibir página | Cuando escribes una dirección, tu navegador pide la página a otra computadora y la muestra. |
| 2:00 | Una página sin estilo vs. la misma con estilo | Misma página, dos versiones: la primera solo tiene contenido; la segunda tiene color y orden. |
| 3:30 | HTML = contenido / CSS = estilo | HTML es el esqueleto y el contenido. CSS es la ropa y la decoración. |
| 4:45 | "Lo que vamos a construir" | Al final del curso tendrás tu propia página de perfil. |
| 5:30 | Enlace a CodePen | Abre el enlace de la descripción: solo necesitas tu navegador. |

**Práctica (pausa):** abrir el editor en línea y reconocer los tres paneles: HTML, CSS y resultado.

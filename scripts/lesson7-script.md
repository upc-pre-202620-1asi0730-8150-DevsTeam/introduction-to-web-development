# Lección 7: Recomendaciones y errores comunes (7 min)

**Objetivo:** evitar los errores más frecuentes y saber dónde seguir aprendiendo.

1. (0:00) Etiquetas sin cerrar.
2. (1:30) Olvidar el punto y coma `;` al final de una propiedad CSS.
3. (2:30) Escribir mal el nombre de una propiedad o un color.
4. (3:30) Ruta de imagen incorrecta y `alt` vacío.
5. (4:30) Cómo depurar: leer el código línea por línea y comentar partes con `<!-- -->` y `/* */`.
6. (5:30) Recursos para seguir: MDN Web Docs. Invitar a compartir el resultado con el formulario.

# Lección 2: Estructura básica de HTML (8 min)

**Objetivo:** conocer etiquetas, elementos y atributos, y escribir la primera página.

1. (0:00) Una etiqueta es una instrucción entre `< >`. Casi todas se abren y se cierran: `<p>` ... `</p>`.
2. (1:30) Elemento = etiqueta de apertura + contenido + etiqueta de cierre.
3. (2:30) Esqueleto: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`. En el `<head>` va información de la página; en el `<body>`, lo que se ve.
4. (4:00) Atributos: dan información extra a una etiqueta, por ejemplo `lang="es"`.
5. (5:00) **Pausa de práctica:** escribir un `<h1>` con tu nombre y un `<p>` con una frase.
6. (7:00) Comparar con `/completed-examples/lesson2-completed.html`.
